# Clasificación con Naive Bayes Gaussiano: Un Enfoque desde los Fundamentos

Este repositorio no es solo una implementación técnica, sino el resultado de mi proceso de **autoaprendizaje y profundización en los fundamentos matemáticos** detrás del Machine Learning. Como apasionado de las matemáticas, creo firmemente que para dominar un algoritmo no basta con aplicar una librería, sino que es vital comprender la estadística que lo sustenta.

## 🎯 Objetivo del Proyecto

Desarrollar un modelo robusto de clasificación para el dataset *Wine*, enfocándome en la correcta modelación de las **distribuciones gaussianas** de las variables predictoras. Este proyecto refleja mi compromiso con la precisión analítica y mi búsqueda constante por la superación profesional en el campo de la Ciencia de Datos.

## 🧠 Lo que este proyecto demuestra

* **Fundamentos Matemáticos:** Implementación consciente del Teorema de Bayes asumiendo distribuciones normales (Gaussianas) para variables continuas.
* **Capacidad de Autoaprendizaje:** Investigación independiente sobre el comportamiento de las fronteras de decisión y la independencia condicional.
* **Análisis Crítico:** No solo se presenta el resultado, sino la interpretación de métricas (Precisión, Recall, Matriz de Confusión) para asegurar la fiabilidad del modelo.
* **Dominio de R Markdown:** Generación de documentación técnica profesional, reproducible y visualmente atractiva para perfiles directivos.

## 🛠️ Stack Técnico

* **Lenguaje:** R (Enfoque en computación estadística).
* **Librerías Key:** `naivebayes`, `ggplot2` (visualización avanzada), `caret` (evaluación de modelos).
* **Documentación:** R Markdown e integración con GitHub Pages.

## 📈 Resumen Analítico

En este estudio se analiza la separación de clases mediante la densidad de probabilidad, permitiendo entender cómo el algoritmo asigna pesos a las características químicas del vino para su clasificación final.
